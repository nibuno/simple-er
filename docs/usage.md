# 使い方

SimpleER の操作・保存・モデリング機能の詳細です。概要は [README](../README.md) を参照してください。

## 画面構成

- 通常はヘッダーとキャンバスだけを表示します。
- テーブル一覧：ヘッダー左端のボタンで、テーブル・リレーションの一覧を開閉します（初期状態は閉じています。開閉状態はブラウザに記憶）。絞り込みができ、項目を選ぶとキャンバス上の位置へ移動します。
- テーブルの編集は、テーブルの「⋯」から開く編集画面で行います。DDL（PostgreSQL形式）のプレビューは編集画面の下部に折りたたんで表示します。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `T` | テーブルを追加 |
| `Delete` / `⌫` | 選択中の外部キー・テーブルを削除 |
| `⌘Z` / `⇧⌘Z` | 元に戻す / やり直す |
| `Esc` | 選択・接続・編集を取り消す |
| `Enter`（カラム行で2回） | 接続元・接続先を指定して外部キーを登録 |
| `F2`（カラム行） | 名前を直接編集 |

## テーブルとカラム

- **選択**：見出しやカラム行をクリック。関連する線とカラムを強調します。
- **追加**：物理名、任意の論理名（日本語名）、カラム、型を入力。カラム行の「主キー」「一意」で設定し、「参照先」から外部キーを登録します。複合キーやインデックスは同じ画面の一覧で編集します。
- **編集**：各テーブルの「⋯」（ポインターを乗せたときと選択中に表示）から名前の変更、カラムの追加・削除・並べ替え。残ったカラムの接続は保持されます。
- **直接編集**：テーブル名・カラム名をダブルクリックすると、現在の表示名（物理名／論理名）を編集できます。`Enter` で確定、`Esc` でキャンセル。
- **表示名**：図の表示を物理名／論理名で切り替えます。論理名が空欄の場合は物理名を表示します。自動接続は物理名から判定します。

## キャンバス操作

- **ズーム**：トラックパッドのピンチで、ポインター位置を中心に 25〜400% で拡大縮小。右下の拡大率表示も連動します。
- **移動**：2本指スクロール、または空白部分のドラッグ。
- **テーブルの移動**：見出しをドラッグ。自動の線は接続面と経路を追従します。ほかのテーブルは動きません。

## 外部キーと線

- **ドラッグで接続**：カラム行にポインターを乗せると左右の端に点が出ます。点から別テーブルのカラムへドラッグすると接続します（参照の向きは主キー・一意制約から判定）。カラム行のクリックは選択だけで、接続は始まりません。
- **自己参照・複合外部キー**：編集画面の「参照先」で設定します。
- **線の選択**：「外部キーを編集」で参照設定へ移動。「外部キーを削除」は複合外部キーの線をすべて削除します。
- **経路の調整**：線を選択して「経路を調整」を押すと、調整可能な縦区間につまみを表示します。ドラッグまたは左右キーで動かせます。「線を自動に戻す」でその外部キーの全線を自動経路に戻します。
- **関係の表示**：1／多を線の両端に表示します。「外部キーを編集」から関係ラベルと最小件数を設定できます。1対1は参照元の主キー・一意制約から判定し、通常のインデックスは判定に使いません。旧データの最小件数は推測せず、未指定の間は最大件数だけを表示します。

## 自動で接続

`user_id → users.id` のような名前から候補を表示し、選択した候補をまとめて接続します。テーブルは移動しません。

`*_id` とテーブル名（同名または基本的な単数・複数形）を照合し、参照先の主キーが1つで型が一致する場合に候補を出します。接続済みのカラムは対象外です。曖昧な候補・複合主キー・型の不一致は見送り、理由を表示します。データベースの制約を読み取る機能ではありません。

## 整頓

参照先を左、参照元を右へ配置します。一本道は上端を揃え、分岐は接続先に合わせて上下順を調整します。循環は同じ列、独立したテーブル群は空いた領域へ配置します。実寸と関係ラベルの幅で間隔を取り、現在位置・画面幅には依存しません。

線はテーブルを避け、短い段差と不要な曲がりを抑えます。同じカラムの接続点と水平部分は共有できます。「元に戻す」で手動経路も復元できます。交差を減らす処理はありますが、どの図でも交差ゼロや最短経路になる保証はありません。

## 複合キー・制約

- カラム行の「主キー」は一つの主キーの構成カラム、「一意」はそのカラムだけの一意制約です。複数の「一意」チェックは別々の制約になります。
- 下部の「キー・インデックス」は一つの定義を一行で表示します。「＋ 追加」や「編集」で対象カラムを選び、←／→で順序を変更できます。複合一意制約はここで設定します。
- カラム行の「＋ 参照先」から外部キーを追加し、既存の `users.id ↗` などを押すと編集できます。一つのカラムが複数の外部キーに含まれる場合は、すべての参照先を表示します。
- 外部キーは左右に参照元と参照先を並べて設定します。参照先には主キー・一意制約が候補として表示され、候補が一つの場合は自動選択します。複合キーは複数行で対応を指定します。
- 参照先には同じ順序・個数の主キーまたは一意制約が必要です。通常のインデックスは参照先にできません。
- 定義の「編集を取り消す」はその定義だけを戻します。「完了」で一覧へ戻り、テーブルの「変更を反映」で図に保存します。テーブルの「キャンセル」はその画面での編集全体を取り消します。
- 参照元カラムを削除すると、そのカラムを含む制約全体を削除します。参照先カラム・テーブルの削除や主キー・一意制約の変更時は、影響する外部キーを参照先未設定として残します。

## 要確認

「要確認」は参照先未設定の外部キーと、移行できなかった旧データの線をまとめて表示します。

- 参照先未設定の外部キーは保持され、線は描かれません。「編集」から参照先を設定できます。
- 旧データの線は、単一主キーとFK表示から方向を一意に判断できるものだけ移行します。曖昧な線は `unresolvedEdges` に元の記録を残します。表示する列番号は移行前の位置です。
- 旧データの線は、必要な参照関係を設定してから「破棄」できます。破棄は保存されますが、再読み込みまでは「元に戻す」で復元できます。

## 保存

### 自動保存

図は操作確定時に、開いているブラウザへ自動保存されます。同じブラウザ・同じURLで再開してください。ブラウザのデータ削除やプライベートブラウジングでは保持されない場合があります。Web版とローカル版、開発サーバーの保存領域はそれぞれ別です。

### ファイル

「ファイルに保存」で JSON を書き出し、「ファイルを開く」で復元します。テーブル、カラム、接続、手動で調整した線の位置を含みます。読み込みに失敗した場合は現在の図を保持し、成功後も「元に戻す」で直前の図に戻れます。

### 別タブとの競合

同じ図を別タブで変更すると、自動保存を停止します。この画面の編集は「ファイルに保存」で残せます。「保存されている図を読み込む」で別タブの内容を取り込み、自動保存を再開します。読み込み時に編集履歴をリセットするため、残したい編集は先にファイルへ保存してください。

### 旧版からの移行

保存キーは旧版と共通です。旧版の JSON（version 1）は読み込めますが、version 2 で保存した図は旧版アプリでは読み込めません。移行時、自動保存の元データは `.v1-backup` キーへ退避します。

## 制限

- 上限は 40 テーブル、各 60 カラム、200 接続です。
- DDL はプレビュー用で、データベースへの出力や制約の型互換性の検査は行いません。
- 元に戻す・やり直すの履歴は起動中のみ保持します。
