# 使い方

SimpleER の操作・保存・モデリング機能の詳細です。概要は [README](../README.md) を参照してください。

## 画面構成

- 通常はヘッダーとキャンバスだけを表示します。
- ヘッダー左端のボタンでテーブル一覧を開閉します。`⌘F`（Windows は `Ctrl+F`）で検索欄に移動します。テーブル名・カラム名は物理名と論理名のどちらでも検索でき、テーブルとカラムの説明も対象です。候補を選ぶと、そのテーブルが画面に表示されます。Enter で先頭の候補を選べます。
- テーブルを選んで「関連だけ表示」を押すと、そのテーブルと線で直接つながるテーブルが表示されます。「関連表示を解除」で元の表示に戻ります。部分表示のまま編集でき、自動保存と書き出しには図全体が含まれます。
- テーブルの編集は、テーブルの「⋯」から開く編集画面で行います。「ファイル」で選んだ形式の DDL プレビューは編集画面の下部に折りたたんで表示します。
- 図が空のときは、中央に「テーブルを追加」「ファイルを開く」「サンプルを開く」を表示します。
- 「ファイル」→「使い方」（`?`）で、ショートカットと外部キーの作り方を表示します。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `T` | テーブルを追加 |
| `⌘F` / `Ctrl+F` | 図の中を検索 |
| `Delete` / `⌫` | 選択中の外部キー・テーブルを削除 |
| `⌘Z` / `⇧⌘Z` | 元に戻す / やり直す |
| `Esc` | 選択・接続・編集を取り消す |
| `Enter`（カラム行で2回） | 接続元・接続先を指定して外部キーを登録 |
| `F2`（カラム行） | 名前を直接編集 |
| `?` | 使い方を表示 |

## テーブルとカラム

- **選択**：見出しやカラム行をクリック。関連する線とカラムを強調します。
- **追加**：物理名、任意の論理名（日本語名）、カラム、型を入力。カラム行の「主キー」「一意」で設定し、「参照先」から外部キーを登録します。複合キーやインデックスは同じ画面の一覧で編集します。
- 「NN」で NOT NULL を設定し、「詳細」で既定値（SQL 式）、整数型の自動採番、カラムの説明を編集します。図では型の下に NN（NOT NULL）、DF（既定値）、AI（自動採番）が表示されます。説明はテーブルの見出しやカラムにポインターを置くと読めます。
- 外部キーの「親の削除時」「親の更新時」で参照動作を選べます。接続線を選ぶと設定値が表示されます。
- **編集**：各テーブルの「⋯」（ポインターを乗せたときと選択中に表示）から名前の変更、カラムの追加・削除・並べ替え。残ったカラムの接続は保持されます。
- テーブル名やカラム名を**ダブルクリック**すると、表示中の物理名または論理名を編集できます。`Enter` で確定します。カラム名を確定すると、次のカラムを入力できます。
- テーブルを選んで最下部の **「＋ カラム」** を押し、名前を入力します。`Enter` を押すたびに型が `text` のカラムを1つ追加します。論理名の表示中は、物理名に `column_1` などの空き番号を使います。`Esc` で入力中の名前を取り消して終了します。
- **表示名**：図の表示を物理名／論理名で切り替えます。論理名が空欄の場合は物理名を表示します。自動接続は物理名から判定します。

## キャンバス操作

- **ズーム**：トラックパッドのピンチで、ポインター位置を中心に 25〜400% で拡大縮小。右下の拡大率表示も連動します。
- **移動**：2本指スクロール、または空白部分のドラッグ。
- **テーブルの移動**：見出しをドラッグ。自動の線は接続面と経路を追従します。ほかのテーブルは動きません。

## テーブルの色と囲み

- テーブルの「⋯」で「見出しの色」を選べます。スキーマ名を入力すると、見出しのテーブル名の上に表示されます。
- `Shift` を押しながらテーブルをクリックし、`⌘G`（Windows は `Ctrl+G`）で囲みに名前を付けます。「囲む」を先に押してテーブルを選ぶこともできます。
- 囲みの見出しをドラッグすると、所属テーブルが一緒に動きます。見出しをクリックすると、名前や所属テーブルの変更、囲みの解除ができます。
- 「関連だけ表示」では表示中のテーブルに合わせて枠が縮みます。囲みを動かすと、非表示の所属テーブルも同じ距離だけ動きます。

## 外部キーと線

- **ドラッグで接続**：カラム行にポインターを乗せると左右の端に点が出ます。点から別テーブルのカラムへドラッグすると接続します（参照の向きは主キー・一意制約から判定）。カラム行のクリックは選択だけで、接続は始まりません。
- **自己参照・複合外部キー**：編集画面の「参照先」で設定します。
- **線の選択**：「外部キーを編集」で参照設定へ移動。「外部キーを削除」は複合外部キーの線をすべて削除します。
- **経路の調整**：線を選択して「経路を調整」を押すと、調整可能な縦区間につまみを表示します。ドラッグまたは左右キーで動かせます。「線を自動に戻す」でその外部キーの全線を自動経路に戻します。
- **関係の表示**：1／多を線の両端に表示します。「外部キーを編集」から関係ラベルと最小件数を設定できます。1対1は参照元の主キー・一意制約から判定し、通常のインデックスは判定に使いません。旧データの最小件数は推測せず、未指定の間は最大件数だけを表示します。

## 自動で接続

`user_id → users.id` のような名前から候補を表示し、選択した候補をまとめて接続します。テーブルは移動しません。

`*_id` とテーブル名（同名または基本的な単数・複数形）を照合し、参照先の主キーが1つで型が一致する場合に候補を出します。接続済みのカラムは対象外です。曖昧な候補・複合主キー・型の不一致は見送り、理由を表示します。データベースの制約を読み取る機能ではありません。

## 整頓

参照先を左、参照元を右へ配置します。一本道は上端を揃え、分岐は接続先に合わせて上下順を調整します。循環は同じ列、独立したテーブル群は空いた領域へ配置します。実寸と関係ラベルの幅で間隔を取り、現在位置・画面幅には依存しません。

線はテーブルを避け、短い段差と不要な曲がりを抑えます。同じカラムの接続点と水平部分は共有できます。「元に戻す」で手動経路も復元できます。交差を減らす処理はありますが、どの図でも交差ゼロや最短経路になる保証はありません。

## 複合キー・制約

- カラム行の「主キー」は一つの主キーの構成カラム、「一意」はそのカラムだけの一意制約です。複数の「一意」チェックは別々の制約になります。
- 下部の「キー・インデックス」は一つの定義を一行で表示します。「＋ 追加」や「編集」で対象カラムを選び、←／→で順序を変更できます。複合一意制約はここで設定します。
- カラム行の「＋ 参照先」から外部キーを追加し、既存の `users.id ↗` などを押すと編集できます。一つのカラムが複数の外部キーに含まれる場合は、すべての参照先を表示します。
- 外部キーは左右に参照元と参照先を並べて設定します。参照先には主キー・一意制約が候補として表示され、候補が一つの場合は自動選択します。複合キーは複数行で対応を指定します。
- 参照先には同じ順序・個数の主キーまたは一意制約が必要です。通常のインデックスは参照先にできません。
- 定義の「編集を取り消す」はその定義だけを戻します。「完了」で一覧へ戻り、テーブルの「変更を反映」で図に保存します。テーブルの「キャンセル」はその画面での編集全体を取り消します。
- 参照元カラムを削除すると、そのカラムを含む制約全体を削除します。参照先カラム・テーブルの削除や主キー・一意制約の変更時は、影響する外部キーを参照先未設定として残します。

## 要確認

「要確認」は参照先未設定の外部キーと、移行できなかった旧データの線をまとめて表示します。

- 参照先未設定の外部キーは保持され、線は描かれません。「編集」から参照先を設定できます。
- 旧データの線は、単一主キーとFK表示から方向を一意に判断できるものだけ移行します。曖昧な線は `unresolvedEdges` に元の記録を残します。表示する列番号は移行前の位置です。
- 旧データの線は、必要な参照関係を設定してから「破棄」できます。破棄は保存されますが、再読み込みまでは「元に戻す」で復元できます。

## 保存

### 図の一覧

左上の図名をクリックして入力し、Enter で確定します。「ファイル」→「図の一覧」には図の名前と更新日時が並びます。図名を押すと開きます。「新しく作る」は空の図を追加します。各行の「操作」から複製、名前の変更、削除ができます。最後の図を削除すると空の図が開きます。

「新しい図」「ファイルを開く」「サンプルを開く」はそれぞれ別の図を追加します。以前の図は一覧から開けます。「元に戻す」「やり直す」は開いている図の編集に使います。

### 自動保存

図は操作確定時に、開いているブラウザへ自動保存されます。再読み込みすると、そのタブで最後に開いていた図が表示されます。ブラウザのデータ削除やプライベートブラウジングでは保持されない場合があります。Web版とローカル版、開発サーバーの保存領域はそれぞれ別です。

### ファイル

「ファイルに保存」で JSON を書き出し、「ファイルを開く」で復元します。テーブル、カラム、接続、手動で調整した線の位置を含みます。ファイルを開くと一覧に図が加わります。読み込みに失敗した場合は現在の図を保持します。

「SVG で保存」「PNG で保存」で、表示中の物理名・論理名を使って図全体を書き出せます。画像は白い背景で、周囲に余白が付きます。「DDL の形式」で PostgreSQL・MySQL・SQLite を選び、「全テーブルの DDL をコピー」または「全テーブルの DDL を保存」を押します。初期値は PostgreSQL です。選んだ形式は図に保存され、テーブル編集画面のプレビューにも反映されます。

「ファイル」または空の図の「DDL を読み込む」から、PostgreSQL・MySQL・SQLite の `CREATE TABLE` 文を貼り付けるか、SQL ファイルを開きます。「今の図に追加」「新しい図」のどちらかを選び、「読み込む」を押すと、読み込んだテーブルが自動で並びます。外部キーは接続線に、テーブルやカラムのコメントは説明になります。PostgreSQL では説明を `COMMENT ON`、MySQL では `COMMENT`、SQLite では SQL コメントに書き出します。論理名や関係ラベル・多重度も SQL コメントに残します。図の配置や線の引き方まで保存するには JSON を使います。

スキーマ名は、PostgreSQL ではスキーマ、MySQL ではデータベース、SQLite では同じ接続で `ATTACH` したデータベース名として使います。DDL の実行前に出力先を用意してください。SQLite でスキーマ名を省略すると通常は `main` が使われます。PostgreSQL と MySQL ではスキーマをまたぐ外部キーも書き出せます。SQLite では同じデータベース内の参照に限られます。SimpleER の図では、スキーマが異なる場合も各テーブルに異なる物理名が必要です。

UUID は MySQL では `CHAR(36)`、SQLite では `TEXT` になります。MySQL のキーに使う `text` は `VARCHAR(255)`、SQLite の日時・JSON は `TEXT`、真偽値は `INTEGER` に変換します。書き出し時に型が変わるカラムには元の型を SQL コメントに残し、SimpleER で再度開くときに復元します。独自の型名と既定値の式は、出力先の DB で使えるものを指定してください。

自動採番には PostgreSQL の SERIAL・IDENTITY、MySQL の AUTO_INCREMENT、SQLite の INTEGER PRIMARY KEY AUTOINCREMENT を使います。PostgreSQL の ALWAYS と採番オプションは、MySQL・SQLite の実行時には適用されません。SQLite の自動採番には単独の主キーが必要です。MySQL の外部キーに SET DEFAULT を指定した場合など、書き出せない定義があるときは画面に理由を表示します。

読み込みでは MySQL の ENGINE・CHARSET、SQLite の STRICT・WITHOUT ROWID などのテーブルオプションを読み飛ばします。

「ファイル」→「定義書を保存（Markdown）」で、図の名前と出力日、テーブル一覧、各テーブルのカラム・外部キー・インデックス・一意制約をまとめて保存できます。「定義書を保存（CSV）」では、同じ内容をカラムごとに1行にまとめます。CSV は Excel で開ける UTF-8（BOM 付き）です。どちらも物理名と論理名を併記し、図で選択中の表示名を先に載せます。

「Mermaid を読み込む」では、`erDiagram` を貼り付けるか、`.mmd` ファイルを開きます。リレーションの記号とラベルはテーブル間の線に、属性のコメントは80文字以内ならカラムの論理名に、それを超える場合は説明に読み込みます。「Mermaid をコピー」「Mermaid を保存」で書き出せます。説明・NOT NULL・既定値・IDENTITY・複合キー・外部キーの参照カラムと参照動作を SimpleER に戻すときは、`%% simple-er-` で始まる補足コメントも残してください。

読み込めない文があると、行番号と理由が表示されます。「読めた分を読み込む」で続けるか、元のテキストを直して読み込み直してください。⌘Z で読み込みをまとめて取り消せます。「新しい図」に読み込んだ場合は、その図が空に戻ります。

ファイル名には図の名前を使います。サンプルにはサンプル名を、図名のない JSON にはファイル名を使います。旧版の日付入り自動ファイル名は「無題の図」として開きます。

### 別タブとの競合

別のタブで同じ図を変更・削除すると、自動保存を停止します。手元の編集を残すには「別の図として保存」か「ファイルに保存」を使います。「保存されている図を読み込む」を押すと、別タブの変更を読み込み、編集履歴をリセットして自動保存を再開します。

### 旧版からの移行

旧版で開いていた図と「前の図に戻す」の退避データは、一覧から開けます。どちらも編集するまでは「更新日時不明」と表示します。version 1・2 の JSON を開くと、テーブルとカラムの論理名を残したまま、同じ内容を説明に引き継ぎます。保存時は version 3 になります。version 1 の元データは最初に編集を保存するときに `.v1-backup` キーへ退避します。退避や自動保存に必要な空き容量が足りないときは、ファイルへ保存するか、一覧から不要な図を削除してください。

## 制限

- 上限は 150 テーブル、各 60 カラム、400 接続です。複合外部キーはカラムの組ごとに 1 接続と数えます。JSON ファイルは 16 MB まで読み込めます。
- DDL はプレビュー用で、データベースへの出力や制約の型互換性の検査は行いません。
- 元に戻す・やり直すの履歴は起動中のみ保持します。
