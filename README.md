# SimpleER

線や配置の調整に手間をかけず、ER図を書くためのローカルツール。画面上の名称は「SimpleER」です。

`start.command` をダブルクリックすると、ローカルサーバーとブラウザが開きます。Python 3 が必要です。このMacでは利用できることを確認しています。

表示先は常に http://127.0.0.1:8765/ です。起動用ウィンドウを閉じるか Ctrl+C で終了します。再起動するにはもう一度 `start.command` を開いてください。

## 操作

- テーブルを追加：物理名、任意の論理名（日本語名）、カラム、型、主キー・外部キーを入力。
- 表示名：図の表示を物理名／論理名に切り替え。論理名が空欄の場合は物理名を表示。自動接続は物理名から判定。
- 各テーブルの「編集」：名前の変更、カラムの追加・削除・並べ替え。残ったカラムの接続は保持されます。
- 拡大・縮小：キャンバス上でトラックパッドをピンチすると、ポインター位置を中心に25〜400%でズーム。右下の拡大率表示も連動します。
- キャンバスの移動：Macのトラックパッドで2本指スクロールすると上下左右に移動。空白部分のドラッグでも移動できます。
- テーブルの見出しをドラッグ：線は接続方向を保って追従。
- カラムを2つクリック：手動で接続。
- 線をクリックしてつまみをドラッグ：通り道を調整。
- 自動で接続：`user_id → users.id` のような名前から候補を表示し、選択した候補をまとめて接続。テーブルは移動しません。
- 整頓：現在の並び順をもとにテーブルを行・列に揃え、重ならない間隔で配置。接続関係は保持し、「元に戻す」で配置を復元できます。
- 元に戻す・やり直す：編集、接続、削除、読み込みにも対応（履歴は起動中のみ）。

## 保存

図は操作確定時に、このURLを開いたブラウザに自動保存されます。同じブラウザ・同じURLで再開してください。ブラウザのデータ削除やプライベートブラウジングでは保持されない場合があります。

「ファイルに保存」でJSONのバックアップを作り、「ファイルを開く」で復元できます。テーブル、カラム、接続、手動で調整した線の位置を含みます。読み込み失敗時には現在の図を保持します。読み込み成功後も「元に戻す」で直前の図に戻れます。

保存・編集データの外部送信は行いません。以前の公開版とローカル版のデータは別です。今回、公開版は更新していません。

## 自動接続の範囲

`*_id` とテーブル名（同名または基本的な単数・複数形）を照合し、参照先の主キーが1つで型が一致する場合に候補を出します。接続済みのカラムは対象外です。曖昧な候補・複合主キー・型の不一致は見送り、理由を表示します。データベースの制約を読み取る機能ではありません。

現在の上限は40テーブル、各60カラム、200接続です。大きな図での速度は今後の改善対象です。自己参照や複合外部キー、線同士の重なりの自動解消は未対応です。

## 今後

- Mermaid形式への出力（関係情報の出力。手動配置や線の経路をそのまま再現できるものではありません）
- SVG・PNGでの画像出力

保存形式は `format: "er-sketch"`, `version: 1`。テーブルとカラムの識別子を名前から分離しているため、編集時に関係を保ち、今後の出力機能からも同じ図のデータを利用できます。

## 開発時の確認

React + TypeScript（strict）+ Viteで実装しています。Node.js 22.18以降を使用してください。

```sh
npm ci
npm run dev       # 開発用: http://127.0.0.1:5173/
npm run build     # 型チェックと dist/ の生成
npm test          # 保存・接続・整頓・履歴・Reactの操作を検証
npm run format    # ソースコードを整形
```

通常利用は従来どおり `start.command` で起動できます。生成済みの `dist/` を配信するため、通常起動にnpmは不要です。ソース変更後は `npm run build` で更新します。開発用のURLは保存領域が異なるため、従来の図を確認する場合はビルド後に http://127.0.0.1:8765/ を再読み込みしてください。

- `src/App.tsx`：図の状態・履歴・保存・ツールバー
- `src/DiagramCanvas.tsx`：SVG描画、ドラッグ、拡大縮小
- `src/Dialogs.tsx`：テーブル編集と自動接続の候補
- `src/types.ts`：テーブル・カラム・接続の型
- `src/model.ts`：保存形式の検証・編集・接続推測
- `src/geometry.ts` / `src/layout.ts`：線の経路計算・整頓
- `src/history.ts`：元に戻す・やり直す

保存キーとJSON形式は旧版と共通です。`dist/` は生成物なので直接編集しません。
