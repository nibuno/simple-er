# SimpleCanvas

構成図と、その理由を書くためのローカルキャンバス。SimpleERと同じ配色・文字・線の雰囲気を使い、別の画面と保存領域で動きます。

## 起動

リポジトリ直下の `start-canvas.command` をダブルクリックしてください。
Python 3 の標準ライブラリだけで起動し、[http://127.0.0.1:8766/](http://127.0.0.1:8766/) を開きます。
終了するときは起動したターミナルで Ctrl+C。次回も同じURL・ブラウザで開いてください。

通常利用にnpmやインターネット接続は不要です。初回は「通知処理の設計」のサンプルを表示します。
「ファイル → 新しいキャンバス」で空の図から始められます。サンプルの再読み込み、新規作成、ファイルの読み込みも、起動中は元に戻せます。

## 図とメモ

- **図形**：上部の「図形」に箱・楕円・ひし形・円柱のアイコンが並びます。アイコンを押すと、表示中の中央付近で他の図形・線・ラベルと重ならない場所に置き、その形で入力を始めます。入力中の図形は確定するまで既存の線の経路に影響しません。名前はホバーやキーボードでのフォーカス時に表示し、Bで直前に使った形を追加します。名前と説明は空欄で始まり、何も入力せずに閉じると追加されません。空白だけの入力も同じ扱いです。追加済みの図形は、選択パネルの「図形」で形を変更できます。
- **文章**：「メモ」または N。余白のダブルクリックでも、その位置に直接書き始められます。通常の文章を貼り付けるとメモになります。
- **色**：図形・メモ・囲みを選び、選択パネルの「塗り」と「線」から変更します。接続線は「線」のみ。複数選択にもまとめて適用でき、1回で元に戻せます。赤・黄・緑・青をすぐ選べ、「他の色」から灰・橙・青緑・紫・ピンク、透明、白／黒、任意の色コードを選べます。「標準」で元の配色へ戻します。濃い塗り色では文字色を読みやすい色へ切り替えます。色はJSON・SVG・PNGに保存されます。
- **図形の文字**：クリックで図形を選択し、名前や説明をダブルクリック（または選択中の図形の文字をもう一度クリック）すると、その位置で編集できます。文字をドラッグした場合は図形を移動します。名前欄の Enter・Tabで説明へ移り、説明欄の Enterは改行します。選択後の Enter、「編集」からも開始できます。⌘ Enter・「完了」・ほかの場所のクリックで確定し、Escで取り消します。名前と説明はまとめて1回で元に戻せます。
- **入力中の表示**：図形の輪郭を残し、編集の開始・確定・取り消しで倍率と表示位置は変えません。文章が増えると入力欄と図形の表示を広げ、画面内に収まらない長文は入力欄でスクロールできます。入力欄が画面外にはみ出した場合だけ、倍率を保って表示位置を調整し、編集後に元へ戻します。入力中に表示を変えた場合は、その表示を保ちます。編集後に選択パネルは開きません。図形の余白を選ぶと、形・サイズ・メモのパネルを開けます。
- **メモ・囲みの編集**：ダブルクリック、選択後の Enter、または「編集」。図の上の入力欄で編集し、⌘ Enterか「追加」・「完了」で確定します。Escで取り消し、ほかの場所のクリックでも確定します。新規の図形やメモは、入力がある場合だけ保存されます。
- **図形のメモ**：図形を選ぶと右側に入力欄が出ます。説明は図形の中に表示します。「メモを図に置く」でメモをキャンバス上にも表示できます。選択パネルとキャンバスのメモは同じ内容で、図形を動かすと付属メモも動きます。
- **接続**：「接続」または Cを押して、接続元・接続先の順に選びます。図形やメモにポインタを合わせると上下左右に接続点が出ます。接続点を別の図形へドラッグしても接続でき、何もない場所で離すと、同じ形の図形をその位置に追加して接続します（名前を入れずに閉じると線ごと追加されず、確定した追加は1回で元に戻せます）。タッチ操作では、選択中の要素と「接続」中だけ接続点を表示します。線を選ぶとラベル、破線、向きを編集できます。
- **囲み**：Shift＋クリック、または余白をドラッグして複数選択し、「囲む」または ⌘ G。囲みの見出しを動かすと中の要素も移動します。選択パネルの「囲み」で所属を変え、「内容に合わせる」で枠のサイズを合わせられます。
- **整頓**：今の図形の左右・上下の位置関係を保ち、接続点のずれが小さい部分を揃えて線を引き直します。横並びなら高さ、縦並びなら横位置を揃えます。図形を2つ以上選んだ場合は選択範囲、それ以外はすべての図形が対象です。独立したメモは動かさず、付属メモは図形との位置関係を保って一緒に動かします。表示位置と倍率を保ち、整頓全体を1回で取り消せます。

箱・メモはドラッグで移動。右下のハンドルや「サイズ」で大きさを変更できます。移動・サイズ変更は8px単位に揃え、Altを押すと細かく動かせます。矢印キーでも移動でき、Shiftを押すと移動量が増えます。

選択中の要素は Deleteで削除、⌘ Dで複製、⌘ C / X / Vでコピー・切り取り・貼り付けできます。囲みを削除しても中の要素は残ります。箱を削除するとその接続線は消えますが、図に置いたメモは独立した文章として残ります。

## 表示と取り消し

- 2本指スクロールで移動。Space＋ドラッグ、または手のひらツールでも移動できます。
- ピンチ、Ctrl＋ホイール、右下の＋／−で5〜300%に拡大・縮小。
- 右下の「全体を表示」、または 1で全体を表示します。開いたときは前回の表示位置と倍率を使いますが、図が見えない位置や、全体表示より極端に小さい倍率だった場合は全体を表示し直します。
- ⌘ Zで元に戻す、⌘ Shift Zでやり直し。ドラッグ途中のEscはその移動を取り消します。
- 履歴は最大80操作、開いている間だけ保持します。
- Windowsでは⌘をCtrlに読み替えてください。

## 保存と出力

編集の確定時に、このURLを開いているブラウザへ自動保存します。ブラウザ再読み込み時は入力中の文章も確定して保存します。保存できない場合や別タブで変更された場合は通知し、自動上書きを止めます。ブラウザのデータ削除やプライベートモードでは保持されない場合があるため、持ち出しやバックアップにはJSONを使ってください。

- **ファイルに保存**：編集できる `.simplecanvas.json`。箱、全文のメモ、接続、配置、囲みを含みます。
- **ファイルを開く**：上記JSONを復元。不正なファイルや未対応バージョンは読み込まず、現在の内容を保持します。
- **SVGで保存 / PNGで保存**：図全体を出力します。図に置いたメモを含みます。箱の編集欄にだけ保存したメモは画像に含めず、JSONに保持します。

読めない自動保存データを検出した場合は元のデータを保持し、退避してから保存を再開できます。アプリは図やメモを外部送信しません。

保存形式は `format: "simple-canvas"`, `version: 1`。接続・囲み・メモは要素のIDで参照します。図形の `shape` は `rectangle`・`ellipse`・`diamond`・`cylinder` の4種類です。画面とSVG・PNGは同じ輪郭データを使います。四角形だけを含む従来のファイルも読み込めます。

色は省略可能な `fillColor`・`strokeColor` に保存します。接続線は `strokeColor` のみ。6桁のHEX色と `transparent` を使い、色のない従来のJSONは元の配色で表示します。

色選択は [draw.ioの塗り・輪郭・HEX指定](https://www.drawio.com/docs/manual/styles/shape-styles/)と、[Excalidrawのクイック選択・Open Colorパレット](https://github.com/excalidraw/excalidraw/blob/master/packages/common/src/colors.ts)を参考にしています。

## 現在の範囲

個人用のローカルツールです。自動保存はブラウザごとに現在の1キャンバス。複数の設計を保管するには、名前を付けてJSONに保存してください。入れ子の囲み、画像貼り付け、共同編集は未対応です。

上限は150要素（箱・メモ・囲みの合計）、400接続、メモ6000文字、入力ファイル2MB。PNGは長辺8192px・約2400万画素を上限に縮小します。

接続は図形とメモを避け、曲がりや交差が少ない経路を選びます。図形の移動時にも線を引き直します。図形が重なっている場合や混み合った図では、線の交差・貫通を完全には防げません。線の手動経路編集は未対応です。整頓前の配置へ戻すには「元に戻す」を使います。

整頓は各軸48px以内の移動を候補にし、線の曲がり・交差・長さと移動量を比較して、改善する配置だけを採用します。大きく動かさなければ揃わない部分や、図形・メモとの重なりが増える移動はそのままにします。接続されていない図形は動かしません。

## 開発

リポジトリ直下で実行します。React + TypeScript + ViteをSimpleERと共有し、新しい依存パッケージは追加していません。

```sh
npm ci
npm run dev:canvas    # 通常 http://127.0.0.1:5174/
npm run build:canvas  # dist/canvas/ のみ生成
npm run typecheck
npm test
```

`npm run build` はSimpleERとSimpleCanvasの両方をビルドします。開発URLと通常起動のURLでは自動保存の領域が異なります。

- `src/App.tsx`：編集履歴、自動保存、入出力、ショートカット
- `src/Canvas.tsx`：選択、移動、サイズ、接続、ズーム
- `src/Inspector.tsx`：選択パネルと図の上での編集
- `src/ShapeTextEditor.tsx`：図形の文字位置に重ねる入力欄と、日本語入力・確定・取り消し
- `src/model.ts`：保存形式の検証、囲み、複製、整頓の適用
- `src/layout.ts`：現在の配置を基準にした接続点の調整と配線の評価
- `src/spatial.ts`：図形の範囲・重なり・接続方向の計算
- `src/geometry.ts`：接続点、配線とラベルの配置
- `src/orthogonal.ts`：障害物を避ける経路探索
- `src/shapes.ts`：図形の輪郭と文字の表示範囲
- `src/text.ts`：文字幅の見積もりと折り返し
- `src/export.ts`：SVG・PNG出力

モデルとReact操作のテストは、JSON往復、破損データ、メモの連動、削除時の文章保持、複製時のID再割り当て、選択範囲の整頓、履歴、入力キャンセル、読み込み失敗、別タブ競合、再読み込み直前の入力を検証します。
