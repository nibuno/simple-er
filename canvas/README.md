# SimpleCanvas

構成図を描き、設計の理由をメモに残すツール。SimpleERと同じ配色で、保存先は別です。

## 起動

リポジトリ直下の `start-canvas.command` をダブルクリックすると、[http://127.0.0.1:8766/](http://127.0.0.1:8766/) が開きます。Python 3 だけで動き、npm やネット接続はいりません。終了はターミナルで Ctrl+C。

初回はサンプル「通知処理の設計」が開きます。空の図から始めるときは、左上の「ファイル」（≡）から「新しい図」を選びます。

## 画面

- 左上：図の名前、保存状態、メニュー
- 左：ツール（選択、手のひら、図形、テキスト、接続、囲む、整頓）
- 左下：元に戻す／やり直す
- 右下：表示倍率、全体を表示

要素を選ぶと、すぐ上に操作バーが出ます。線を選ぶと、ラベル・色・破線に加えて、矢印の種類（片方向・双方向・矢印なし）を変えられます。片方向の矢印は向きも反転できます。図形の操作バーでは形・色・メモ・複製・削除を選べます。

## 使い方

- **図形**：ツール列から図形を置き、名前と説明を書きます。箱・人・円柱・クラウドはツール列に、楕円・円・ひし形・画面・書類は「その他の図形」にあります。円は大きさを変えても正円のままです。図形は何も書かずに閉じても残ります。テキストは空のまま閉じると消えます。
- **アイコン**：箱を選んで操作バーの「アイコン」から、名前の横に小さなアイコン（サーバー、キュー、バッチ、メールなど）を付けられます。
- **つなぐ**：図形にポインタを乗せると、辺の外に矢印が出ます。クリックするとその方向に図形を追加してつなぎ、別の図形までドラッグするとその図形とつなぎます。空いた場所で離すと、そこに図形を追加します。
- **テキスト**：余白をダブルクリックすると、その場で書けます。図の説明や判断の理由に使います。
- **メモ**：図形ごとの補足です。操作バーの「メモ」で書き、「図に表示」で図形の横に出せます。図形を動かすと一緒に動きます。
- **メモの一覧**は右上の「メモ」から開きます。「未決」「決定」「懸念」で絞り込み、メモを選ぶと対応する図形が中央に表示されます。状態は各図形の「メモ」で変更できます。
- **テキストから図にする**：[Mermaid の flowchart](#テキストから図にする) を図の余白に貼り付けます。
- **線のラベル**：線をダブルクリックして書きます。
- **囲む**：Shift＋クリックか範囲選択で複数選び、「囲む」（⌘G）。見出しをドラッグすると中身ごと動きます。
- **整頓**：位置関係はそのままに、線がまっすぐになるよう少しずつ揃えます。
- **移動とサイズ**：ドラッグで移動し、四隅と辺のつまみで大きさを変えます。近くの図形の端や中央に揃い、Alt を押すと自由に動かせます。

文字の編集は、ダブルクリックか Enter で始め、Esc か ⌘Enter で確定します。取り消しは ⌘Z です。

## ER 図を開く

円柱や箱を選び、操作バーの「ER 図」でリンク先を選びます。図形に付いた「ER」を押すと SimpleER が開きます。ER 図の上にある「参照元の構成図」から戻れます。

リンク先の名前を変えると、新しい図名が表示されます。削除すると印が「ER?」に変わります。印を押して別の図を選ぶか、「リンクなし」で解除できます。編集用 JSON はリンク情報を保持します。閲覧用 HTML、Markdown、SVG、PNG には印もリンクも入りません。

同じブラウザで両方のアプリを開いてください。ローカルで連携するときは `start.command` で SimpleER を起動し、[同じポートの SimpleCanvas](http://127.0.0.1:8765/canvas/) を使います。8766 の図を移すには「ファイルに保存」してから 8765 側で開きます。Web 版とローカル版でも保存先が分かれます。

## テキストから図にする

次の例を図の余白に貼り付け（⌘V）、読み込み先を選びます。「今の図に追加」した分は ⌘Z 一回で取り消せます。「読み込む…」から `.mmd` ファイルを開くこともできます。

```text
flowchart LR
  user[利用者]:::person --> web[Web<br/>注文を受け付ける]
  subgraph aws[AWS]
    web --> api[API] --> db[(注文DB)]
  end
  api -.->|あとで送る| queue[キュー]:::cloud
```

| 書き方 | 図 |
| --- | --- |
| `flowchart LR` / `graph TD` | 流れの向き。LR は右、RL は左、TB・TD は下、BT は上 |
| `a[名前]` | 箱 |
| `a([名前])` / `a((名前))` / `a{名前}` / `a[(名前)]` / `a[/名前/]` | 楕円・円・ひし形・円柱・書類 |
| `a[名前]:::person` | 形を名前で指定（person・cloud・screen・document・cylinder など） |
| `a[名前<br/>説明]` | 1行目は名前、2行目以降は説明 |
| `a --> b` / `a <--> b` / `a --- b` | 片方向・双方向・矢印なしの実線 |
| `a -.-> b` / `a <-.-> b` / `a -.- b` | 片方向・双方向・矢印なしの破線 |
| `a -->\|ラベル\| b` / `a -- ラベル --> b` | 線のラベル |
| `a --> b & c` | 分岐 |
| `subgraph 名前` 〜 `end` | 囲み |

1行に1つずつ書きます。先に定義した図形も囲みに入れられます。囲みの ID に線をつなげられます。入れ子の囲みは外側の1段にまとめます。`direction` で配置の向き、`classDef`・`class`・`style` で塗りと線の色（3桁・6桁の16進数または透明）を指定できます。読み取れない行があれば、行番号を確認して「読めた分を読み込む」を選べます。

## 案を比べて決める

図名の横の「案を作る」で名前を付け、図の一覧から「案を比べる」を開きます。「この案に決める」で理由を入力して確定すると、決定日時・案の名前・理由が図の一覧、閲覧用 HTML、Markdown に残ります。元の状態に戻すには、もう一度「案を比べる」を開き、「以前の元の図」を選んで決定します。

図の移動は2本指スクロールか Space＋ドラッグ、拡大・縮小はピンチか Ctrl＋ホイールです。Windows では ⌘ を Ctrl に読み替えてください。

## 保存

図は編集するたびに、このブラウザに自動保存されます。メニューの「図の一覧」で、名前と更新日時を見て図を開けます。一覧の「新しく作る」で図を増やし、各図の「操作」から複製、名前の変更、削除ができます。サンプルは別の図で開きます。「読み込む…」では JSON、Mermaid、テキストを貼り付けるかファイルを選び、「今の図に追加」または「新しい図」を選びます。

旧版で編集中だった図と「前の図に戻す」で開けた図も一覧に残ります。容量が足りないときは「ファイルに保存」で編集中の図を残せます。一覧で不要な図を削除すると、空いた容量で保存を再試行します。

「書き出す…」で形式を選び、「保存」または「コピー」を押します。

- **ファイルに保存（JSON）**：図形、テキスト、メモ、線、囲み、色をすべて含みます。
- **画像（SVG / PNG）**：図全体を画像にします。図に表示していないメモは含みません。画面がダークモードでも、画像は明るい配色で出力します。
- **Markdown と画像（zip）**を選ぶと、図の名前で ZIP を保存します。展開して `README.md` を開くと、同じフォルダの `diagram.svg` と、図形ごとのメモと状態を読めます。
- **閲覧用 HTML**を選ぶと、図とメモを1つの HTML ファイルに保存します。ブラウザで開けばオフラインでも図を拡大・移動でき、図形やメモを選ぶと両方が強調されます。
- **画像（PNG）→ コピー**で図全体を PNG として貼り付けられます。図形や線を選んでいると、その部分だけをコピーします。
- **Mermaid**で図全体を flowchart のテキストにします。保存した `.mmd` の中身をキャンバスに貼り付けると、図形、名前、説明、線、ラベル、囲みを自動配置します。メモや自由なテキスト、それらだけを囲む枠やそれらにつながる線、色、アイコン、元の位置やサイズは省きます。

別のタブで同じ図を変更した場合や、保存データが壊れている場合は、上書きせずに知らせます。図やメモを外部に送ることはありません。

## 制限

- 要素は150個、線は400本、テキストは6000文字、読み込むファイルは2MBまで
- PNG は長辺8192px・約2400万画素まで縮小して出力
- 囲みの入れ子、画像の貼り付け、共同編集、線の経路の手動編集には対応していません
- 図形が重なっていたり混み合っていたりすると、線の交差を避けきれないことがあります

## 開発

リポジトリ直下で実行します。React・TypeScript・Vite を SimpleER と共有しています。

```sh
npm ci
npm run dev:canvas    # http://127.0.0.1:5174/
npm run build:canvas  # dist/canvas/ を生成
npm run typecheck
npm test
```

開発用URLと通常起動のURLでは、自動保存の中身は別になります。

| ファイル | 役割 |
| --- | --- |
| `src/App.tsx` | 画面の骨組み、履歴、自動保存、入出力、ショートカット |
| `src/Canvas.tsx` | 選択、移動、サイズ変更、接続、表示倍率 |
| `src/Inspector.tsx` | 操作バーと、テキスト・メモの入力 |
| `src/ShapeTextEditor.tsx` | 図形の名前と説明の入力 |
| `src/model.ts` | 保存形式の検証、囲み、複製、整頓 |
| `src/flowchart.ts` | Mermaid の flowchart の読み取りと自動配置 |
| `src/geometry.ts`・`src/orthogonal.ts`・`src/layout.ts` | 線の経路とラベルの位置 |
| `src/spatial.ts` | 範囲・重なり・揃えガイドの計算 |
| `src/shapes.ts`・`src/text.ts` | 図形の輪郭、文字の折り返し |
| `src/export.ts` | SVG・PNG 出力 |

保存形式は `format: "simple-canvas"`、`version: 1` の JSON です。線・囲み・メモは要素の ID で参照し、図形の `shape` は `rectangle`・`ellipse`・`circle`・`diamond`・`cylinder`・`person`・`cloud`・`screen`・`document` のいずれかで、箱には省略できる `icon` が付きます。色は省略できる `fillColor`・`strokeColor`（6桁のHEXか `transparent`）に入ります。
