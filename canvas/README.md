# SimpleCanvas

構成図と、その理由を書くためのキャンバス。SimpleERと同じ配色で、保存先は別です。

## 起動

リポジトリ直下の `start-canvas.command` をダブルクリックすると、[http://127.0.0.1:8766/](http://127.0.0.1:8766/) が開きます。Python 3 だけで動き、npm やネット接続はいりません。終了はターミナルで Ctrl+C。

初回はサンプル「通知処理の設計」が開きます。空の図から始めるときは、左上のメニュー（≡）から「新しいキャンバス」を選びます。

## 画面

- 左上：図の名前、保存状態、メニュー
- 左：ツール（選択、手のひら、図形、テキスト、接続、囲む、整頓）
- 左下：元に戻す／やり直す
- 右下：表示倍率、全体を表示

要素を選ぶと、すぐ上に操作バーが出ます。図形なら形・色・メモ・複製・削除、線ならラベル・色・破線・向きを変えられます。

## 使い方

- **図形**：ツール列から図形を置き、名前と説明を書きます。箱・人・円柱・クラウドはツール列に、楕円・円・ひし形・画面・書類は「その他の図形」にあります。円は大きさを変えても正円のままです。
- **アイコン**：箱を選んで操作バーの「アイコン」から、名前の横に小さなアイコン（サーバー、キュー、バッチ、メールなど）を付けられます。
- **つなぐ**：図形にポインタを乗せると、辺の外に矢印が出ます。クリックするとその方向に図形を追加してつなぎ、別の図形までドラッグするとその図形とつなぎます。空いた場所で離すと、そこに図形を追加します。
- **テキスト**：余白をダブルクリックすると、その場で書けます。図の説明や判断の理由に使います。
- **メモ**：図形ごとの補足です。操作バーの「メモ」で書き、「図に表示」で図形の横に出せます。図形を動かすと一緒に動きます。
- **線のラベル**：線をダブルクリックして書きます。
- **囲む**：Shift＋クリックか範囲選択で複数選び、「囲む」（⌘G）。見出しをドラッグすると中身ごと動きます。
- **整頓**：位置関係はそのままに、線がまっすぐになるよう少しずつ揃えます。
- **移動とサイズ**：ドラッグで移動し、四隅と辺のつまみで大きさを変えます。近くの図形の端や中央に揃い、Alt を押すと自由に動かせます。

文字の編集は、ダブルクリックか Enter で始め、Esc か ⌘Enter で確定します。取り消しは ⌘Z です。

## ショートカット

| 操作 | キー |

| 図形 / テキストを追加 | B / N |
| 接続 | C |
| 囲む | ⌘G |
| 複製 / コピー / 貼り付け | ⌘D / ⌘C / ⌘V |
| 削除 | Delete |
| 元に戻す / やり直す | ⌘Z / ⌘Shift Z |
| 全体を表示 | 1 |
| ファイルに保存 | ⌘S |
| 使い方 | ? |

キャンバスの移動は2本指スクロールか Space＋ドラッグ、拡大・縮小はピンチか Ctrl＋ホイールです。Windows では ⌘ を Ctrl に読み替えてください。

## 保存

編集するたびに、開いているブラウザへ自動保存します。ブラウザに残るのは今の1枚だけなので、別の図を残すときや持ち出すときは「ファイルに保存」（`.simplecanvas.json`）を使ってください。

- **ファイルに保存 / 開く**：図形、テキスト、メモ、線、囲み、色をすべて含みます。
- **SVG / PNG で保存**：図全体を画像にします。図に表示していないメモは含みません。画面がダークモードでも、画像は明るい配色で出力します。

別のタブで同じ図を変更した場合や、保存データが壊れている場合は、上書きせずに知らせます。図やメモを外部に送ることはありません。

## 制限

- 要素は150個、線は400本、テキストは6000文字、読み込むファイルは2MBまで
- PNG は長辺8192px・約2400万画素まで縮小して出力
- 囲みの入れ子、画像の貼り付け、共同編集、線の経路の手動編集には対応していません
- 図形が重なっていたり混み合っていたりすると、線の交差を避けきれないことがあります

## 開発

リポジトリ直下で実行します。React・TypeScript・Vite を SimpleER と共有しています。

```sh
npm ci
npm run dev:canvas    # http://127.0.0.1:5174/
npm run build:canvas  # dist/canvas/ を生成
npm run typecheck
npm test
```

開発用URLと通常起動のURLでは、自動保存の中身は別になります。

| ファイル | 役割 |
| --- | --- |
| `src/App.tsx` | 画面の骨組み、履歴、自動保存、入出力、ショートカット |
| `src/Canvas.tsx` | 選択、移動、サイズ変更、接続、表示倍率 |
| `src/Inspector.tsx` | 操作バーと、テキスト・メモの入力 |
| `src/ShapeTextEditor.tsx` | 図形の名前と説明の入力 |
| `src/model.ts` | 保存形式の検証、囲み、複製、整頓 |
| `src/geometry.ts`・`src/orthogonal.ts`・`src/layout.ts` | 線の経路とラベルの位置 |
| `src/spatial.ts` | 範囲・重なり・揃えガイドの計算 |
| `src/shapes.ts`・`src/text.ts` | 図形の輪郭、文字の折り返し |
| `src/export.ts` | SVG・PNG 出力 |

保存形式は `format: "simple-canvas"`、`version: 1` の JSON です。線・囲み・メモは要素の ID で参照し、図形の `shape` は `rectangle`・`ellipse`・`circle`・`diamond`・`cylinder`・`person`・`cloud`・`screen`・`document` のいずれかで、箱には省略できる `icon` が付きます。色は省略できる `fillColor`・`strokeColor`（6桁のHEXか `transparent`）に入ります。
